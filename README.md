# Erika's Portfolio (React + Vite)

## Run locally
    npm install
    npm run dev

## Add your assets
Copy into `public/`:
- `IMG20231112123314.jpg`  -> `public/IMG20231112123314.jpg`
- your `images/` folder    -> `public/images/` (GalliumClock, AWS Event Ticketing App)

## Edit content
All text lives in `src/data/` (experience.js, projects.js, skills.js, galleries.js).

## Deploy
Push to `main`. In the repo: Settings -> Pages -> Source: GitHub Actions.
